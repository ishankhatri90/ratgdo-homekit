WHAT IS COUNTED

Install starts, not completions.

A web install start is counted when someone presses an install button. Canceling the serial-port picker, retrying, or starting another flash can add another count. Browser flashing cannot report a verified completion to this static site.

PRIVACY

No tracking profile.

The page requests a tiny public GitHub release asset when installation starts. It sends no site-generated identifier, firmware credentials, Wi-Fi details, serial-port information, or HomeKit code. GitHub may retain ordinary server logs under its own privacy policy.
