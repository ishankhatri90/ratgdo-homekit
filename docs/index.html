AFTER INSTALL · ADD TO APPLE HOME

Your HomeKit setup code

251-02-023

Select the code to copy it. Enter the eight digits 25102023 if asked without dashes.

This code is built into the ESP8266 firmware offered here. You can pair manually without finding the device’s web page.

  1. Finish Wi-Fi setupConnect RATGDO to your home Wi-Fi in the USB installer. Keep your iPhone or iPad on the same local network.
  2. Open Apple HomeTap + → Add Accessory → More Options, then select your RATGDO / Garage Door accessory.
  3. Enter 251-02-023Follow the prompts to finish pairing and choose a room. If Home requests a code, use the eight digits shown above.
Prefer to scan a QR code?

After Wi-Fi setup, use the device link in the USB installer to open RATGDO’s web interface. An unpaired board displays its own HomeKit QR code. Scan it using Apple Home on another screen.

The QR code includes a board-specific identifier, so use the one on your device’s page. The manual code above works for this firmware without that QR code.

RATGDO is missing or already paired

Wait for the board to reboot and join Wi-Fi, then retry from the same local network. Avoid an isolated guest network. If it is already paired, remove it from its previous Apple Home before pairing again. The device web interface also offers Reset HomeKit; this removes existing pairing.

FIRMWARE INSTALLERv2.2.5

Connect. Install. Pair.

For RATGDO Slim v1.00 and v2.00 with a socketed ESP8266 D1 Mini and 1 MB (1024 KB) flash. The firmware uses the RATGDO v2.5 pin layout. It is not for RATGDO32 or RATGDO32 Disco.

  1. Connect over USBUse a data-capable cable. Close serial monitors and other apps using the board.
  2. Select the board’s serial portClick Connect below and choose your USB serial device, often labeled CH340.
  3. Install and set up Wi-FiKeep USB connected until the installer finishes. Follow the setup prompts, then get your HomeKit setup code to add RATGDO to Apple Home.
Changing from a 4 MB layout? Choose the erase option during installation for a clean setup. Erasing removes saved Wi-Fi settings and HomeKit pairing; you will need to configure them again.

RATGDO SLIM HARDWARE

Choose the board you have.

Both Slim versions use the same firmware. Their external-antenna hardware differs.

v1.00

On-board antenna + SMA port

Attach any compatible SMA antenna directly. No ESP module resistor modification is required.

v2.00

SMA-to-IPEX + 2 dBi antenna

Includes an external 2 dBi antenna and feeder. The antenna path works without modifying the ESP module.

BOTH VERSIONS

Built for serviceability

USB-C power, a socketed replaceable ESP8266 D1 Mini, a three-terminal push connector, status LEDs, and a vented enclosure.

OPENER SUPPORT

Check the learn-button color

Security+ 2.0: round yellow learn button. Jackshaft models 8500/RJ020 and 8500C/RJ020C are excluded. Security+ 1.0: purple, brown, orange, or red learn button; support is experimental and may vary by opener or wall panel.

Wire before applying power.

Incorrect wiring can damage the Slim board or garage-door opener. Turn opener power off, verify the terminal labels, and then connect:

RED Wall controlWHITE GroundBLACK Obstruction / control

Use a regulated 5 V supply and the cable specified by your Slim seller. The provided listing says USB-A to USB-C; USB-C to USB-C is not supported by this hardware.

NEED A HAND?

Connection checklist.

The board is missing from the port list

Try another USB data cable and a direct USB port. Slim boards using a CH340 USB-to-serial chip may need the manufacturer’s Windows driver.

The port is busy or connection fails

Close PlatformIO’s serial monitor, Arduino IDE serial monitors, and other browser tabs connected to the board. Unplug and reconnect USB, then try again.

Can this identify my exact board?

The installer confirms the ESP8266 chip family but cannot identify the carrier PCB, flash capacity, wiring, or Slim revision. Confirm you have a Slim v1.00 or v2.00 with a 1 MB D1 Mini before installing.
