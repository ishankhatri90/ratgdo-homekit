Anonymous counters

Pressing a web install button requests a tiny public GitHub Release asset, incrementing its public download count. Direct firmware downloads use their own GitHub counters. This site sets no analytics cookie and sends no site-generated visitor ID, Wi-Fi credential, serial-port information, or HomeKit code. Counts measure attempts and downloads, not successful installations. GitHub may process ordinary request metadata under its own privacy statement.
