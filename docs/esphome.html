Switching from HomeKit?Installing ESPHome replaces the HomeKit firmware. Choose erase during installation, then set up Wi-Fi again. ESPHome connects to Home Assistant; the HomeKit setup code on our other installer page does not apply.

AFTER INSTALL

Connect to Home Assistant.

  1. Set up Wi-FiUse the installer prompts to join your home network. Keep the board powered while it restarts.
  2. Add the ESPHome deviceIn Home Assistant, open Settings → Devices & services and configure the discovered ESPHome device. If it is not discovered, add the ESPHome integration using the board’s IP address.
  3. Want Apple Home too?Use Home Assistant’s HomeKit Bridge integration to expose the garage door. Pair using that bridge’s code, not the native HomeKit firmware code.
