AFTER INSTALL

Connect to Home Assistant.

  1. Set up Wi-FiFinish the installer’s Connect to Wi-Fi prompt after flashing. Missed it? Wait about 90 seconds and join the board’s fallback hotspot to open its own Wi-Fi setup page.
  2. Add the ESPHome deviceIn Home Assistant, open Settings → Devices & services and configure the discovered ESPHome device. If it is not discovered, add the ESPHome integration using the board’s IP address.
  3. Want Apple Home too?Use Home Assistant’s HomeKit Bridge integration to expose the garage door. Pair using that bridge’s code, not the native HomeKit firmware code.

NEED A HAND?

Wi-Fi setup help.

How do I open the Wi-Fi setup page?

About 90 seconds after power-on with no saved network, the board starts an open hotspot named like ratgdov25-XXXXXX Fallback Hotspot. Join it from a phone or computer—a Wi-Fi setup page usually opens automatically; if not, type http://192.168.4.1 into the browser address bar. Select your network there and the board joins it.

I see a white page instead of the Wi-Fi selection page

Open the page as plain http://—never https://—and use the fallback hotspot address above, or the full device name ratgdov25-XXXXXX.local, where XXXXXX is six characters from the board’s MAC address. If the device page still loads blank, the board has no Wi-Fi credentials yet: join its hotspot and open 192.168.4.1.

The installer skipped the Wi-Fi prompt

No reflash needed—use the fallback hotspot route above. You can also re-run the installer with the erase option and finish the Connect to Wi-Fi step.
